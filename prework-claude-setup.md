# Pre-work — Get set up with Claude Code

**Time required:** 10–15 minutes
**Deadline:** Monday before Tuesday Session 1

This prework is the foundation for the next two weeks. It also sets you up for **Phase 2** (Paperclip / agentic operating system), so installing the right tool now matters — installing the wrong one means starting over later.

## What you're installing

You need **Claude Code**, not the Claude.ai chat app or the Claude Desktop chat app.

> Claude Code is Anthropic's developer-facing tool that runs slash commands, skills, and plugins. It's a separate product from the Claude.ai chat website and the Claude Desktop chat app — those are conversation tools without the plugin system we'll be using.

### Pick one surface for Claude Code (any one works)

| Surface | Best for | Install |
|---|---|---|
| **Claude Code Mac/Windows app** | Easiest for non-technical students | Download from claude.ai/code |
| **Claude Code in your browser** | Don't want to install anything | Visit claude.ai/code |
| **VS Code or Cursor extension** | Already use those editors | Install "Claude Code" from extensions |
| **Terminal CLI** | Comfortable with terminal | `npm install -g @anthropic-ai/claude-code` |

You only need ONE. They all share the same plugins, skills, and settings — pick whichever feels most natural.

## Steps

### 1. Create / log in to your Claude account

Go to **claude.ai** and sign up (or log in). Free or Pro both work for this training.

### 2. Install Claude Code (your chosen surface)

- **Mac/Windows app:** download installer from claude.ai/code, run it, sign in
- **Web app:** open claude.ai/code in your browser, sign in
- **VS Code/Cursor:** Extensions → search "Claude Code" → Install → run "Claude: Sign In"
- **CLI:** `npm install -g @anthropic-ai/claude-code` then `claude` to start

### 3. Verify it's working

Open Claude Code and start a new conversation. Type:

> Hello — what version of Claude Code am I running?

If you get a response, you're in.

### 4. Send confirmation

Reply to Wesley on WhatsApp / Skool with:

- Screenshot of Claude Code running
- One-line message: *"I'm in."*

That's it. Tuesday at 22:00 SAST we go live.

## Why this matters for Phase 2

Phase 2 of the program (later) introduces **Paperclip** — an agentic orchestration system that hires AI agents to run your agency. Paperclip uses Claude Code as its agent execution engine — it spawns the `claude` CLI to run tasks. So the skills and personas you configure in Phase 1 carry directly into Phase 2 as agent definitions. **No work thrown away.**

This is why we install Claude Code now, not the chat app — it's the foundation for both phases.
